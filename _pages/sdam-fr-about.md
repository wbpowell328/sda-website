Ceci est une édition web de *Sequential Decision Analytics and Modeling* (2e édition), lue directement dans votre navigateur plutôt que sous forme de PDF.

*Sequential Decision Analytics and Modeling* utilise un style d'enseignement par l'exemple pour illustrer un cadre universel de modélisation des problèmes de décision séquentielle. Ce cadre universel s'applique à *tout* problème de décision séquentielle, depuis les problèmes d'apprentissage actif jusqu'aux problèmes complexes d'allocation de ressources. Les chapitres sont accompagnés de modules Python qui implémentent les modèles, mais le livre devrait aussi être utile aux personnes qui ne souhaitent pas écrire de code.

Le livre est également disponible en [PDF téléchargeable](/assets/papers/sdam-2nd-edition.pdf), ou consultez la [page web du livre](/sdamodeling/) pour un aperçu plus complet, le logiciel Python associé et les supports de cours.
