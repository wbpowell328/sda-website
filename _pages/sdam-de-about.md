Dies ist eine Web-Ausgabe von *Sequential Decision Analytics and Modeling* (2. Auflage), die direkt im Browser gelesen wird, anstatt als PDF.

*Sequential Decision Analytics and Modeling* verwendet einen anhand von Beispielen lehrenden Stil, um ein universelles Framework zur Modellierung sequentieller Entscheidungsprobleme zu veranschaulichen. Das universelle Framework lässt sich auf *jedes* sequentielle Entscheidungsproblem anwenden, von aktiven Lernproblemen bis hin zu komplexen Problemen der Ressourcenallokation. Den Kapiteln sind Python-Module beigefügt, die die Modelle implementiert haben, doch das Buch sollte auch für Personen von Wert sein, die kein Interesse am Schreiben von Code haben.

Das Buch ist auch als [herunterladbares PDF](/assets/papers/sdam-2nd-edition.pdf) verfügbar, oder besuchen Sie die [Webseite des Buchs](/sdamodeling/) für einen umfassenderen Überblick, die zugehörige Python-Software und Kursmaterialien.
