Esta es una edición web de *Sequential Decision Analytics and Modeling* (2ª edición), para leer directamente en su navegador en lugar de en formato PDF.

*Sequential Decision Analytics and Modeling* utiliza un estilo de enseñanza por ejemplos para ilustrar un marco universal para modelar problemas de decisión secuencial. El marco universal se aplica a *cualquier* problema de decisión secuencial, desde problemas de aprendizaje activo hasta problemas complejos de asignación de recursos. Los capítulos vienen acompañados de módulos de Python que han implementado los modelos, pero el libro debería ser de valor incluso para quienes no estén interesados en escribir código.

El libro también está disponible como [PDF descargable](/assets/papers/sdam-2nd-edition.pdf), o consulte la [página web del libro](/sdamodeling/) para obtener una visión más completa, el software de Python que lo acompaña y los materiales del curso.
