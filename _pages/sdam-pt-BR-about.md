Esta é uma edição web de *Sequential Decision Analytics and Modeling* (2ª edição), lida diretamente no seu navegador em vez de como um PDF.

*Sequential Decision Analytics and Modeling* utiliza um estilo de ensino por exemplos para ilustrar uma estrutura universal para modelar problemas de decisão sequencial. A estrutura universal se aplica a *qualquer* problema de decisão sequencial, desde problemas de aprendizado ativo até problemas complexos de alocação de recursos. Os capítulos são acompanhados por módulos Python que implementam os modelos, mas o livro deve ser valioso mesmo para pessoas que não têm interesse em escrever código.

O livro também está disponível como um [PDF para download](/assets/papers/sdam-2nd-edition.pdf), ou veja a [página do livro](/sdamodeling/) para uma visão geral mais completa, o software Python que o acompanha e materiais de curso.
